# Tele-Optics — лабораторная работа № 2

**Тема:** библиотека React. Функциональные компоненты. Роутинг.

SPA-приложение интернет-магазина оптических приборов «Tele-Optics», развивающее
первую лабораторную работу (главная страница из курсовой работы) до полноценного
многопользовательского приложения с маршрутизацией, состоянием и работой с JSON.

## Запуск

```bash
npm install
npm run dev      # режим разработки, http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # просмотр собранной версии
```

`index.html` нельзя открывать двойным кликом (`file://`) — модульные скрипты и
загрузка JSON из `public/data` работают только через dev-сервер или `preview`.

## Что сделано в работе

| Требование ЛР № 2 | Реализация |
| --- | --- |
| Не менее трёх страниц на функциональных компонентах | 11 маршрутов: главная, каталог, категория, товар, избранное, сравнение, корзина, просмотренные, управление каталогом, о компании, контакты + 404 |
| Переиспользуемые компоненты | `ProductCard`, `ProductCarousel`, `ProductGrid`, `Modal`, `QuickViewModal`, `CatalogToolbar`, `ProductForm`, `Pagination`, `Breadcrumbs`, `Rating`, `EmptyState`, `Loader`, `ConfirmDialog`, `ToastStack`, `CompareBar`, `PageHeader` |
| Данные хранятся в состоянии (`state`) | Контексты `DataProvider` (загрузка) и `ShopProvider` (каталог, избранное, сравнение, корзина, множественный выбор, уведомления); локальные состояния фильтров и форм |
| Данные однотипных элементов из JSON | 11 файлов в `public/data` (`products`, `categories`, `brands`, `banners`, `reviews`, `users`, `site`, `navigation`, `heroSlides`, `features`, `goods`) загружаются через `fetch` в `DataProvider` |
| React Router для переходов | `BrowserRouter`, `Routes/Route`, `Link/NavLink`, `useParams`, `useSearchParams`, `useNavigate` |
| Модальное окно (popup) для подробной информации | `Modal` (портал, закрытие по Esc и клику на фон, блокировка прокрутки) + `QuickViewModal` с характеристиками и кнопками действий |
| Функции работы с объектами (добавление, удаление, редактирование, подсветка при множественном выборе) | Страница `/manage`: создание, редактирование и удаление товара (по одному и группой) с валидацией формы; множественный выбор с подсветкой карточек в каталоге управления и в избранном |
| Отзывчивая вёрстка 1920 (1440) → 320 px | Относительные единицы, `clamp()`, grid/flex, медиазапросы 1100/900/640 px |
| Интерактивность | Подсветка при наведении, всплывающие подсказки (`title`, `aria-label`), уведомления, skeleton-загрузка, анимации появления модальных окон и карточек |
| Расширяемость | Новый раздел добавляется одним маршрутом и JSON-файлом без правки существующего кода; действия над объектами вынесены в контекст |

## Структура проекта

```
public/
  assets/            изображения и иконки (перенесены из курсовой)
  data/              JSON-данные приложения
src/
  components/
    catalog/         CatalogToolbar, ProductForm
    common/          Modal, QuickViewModal, Pagination, Breadcrumbs, Rating,
                     EmptyState, Loader, ConfirmDialog, ToastStack, CompareBar,
                     ProductGrid, PageHeader, ScrollToTop
    *.jsx            компоненты главной страницы (Header, Hero, Categories, Hits,
                     Brands, Recommended, Features, OurGoods, About, Consultation,
                     Footer, ProductCard, ProductCarousel, SectionHeader, Icon)
  context/
    DataContext.jsx  загрузка JSON-данных
    ShopContext.jsx  состояние магазина и действия над объектами
  hooks/
    useShopActions.jsx
  pages/             страницы приложения (по одной на маршрут)
  utils/             asset, format, specs
  App.jsx            маршрутизация и общий каркас страниц
  main.jsx           точка входа: BrowserRouter + провайдеры
```

## Маршруты

| Маршрут | Страница |
| --- | --- |
| `/` | Главная (баннеры, акции, категории, хиты, бренды, рекомендуемые, просмотренные) |
| `/catalog` | Каталог: поиск, фильтры (категория, бренд, цена, наличие, скидка), сортировка, пагинация |
| `/catalog/:slug` | Каталог конкретной категории |
| `/product/:id` | Страница товара: характеристики, отзывы, похожие товары |
| `/favorites` | Избранное с множественным выбором и массовыми действиями |
| `/compare` | Таблица сравнения характеристик |
| `/cart` | Корзина: количество, удаление, итог, оформление заказа |
| `/viewed` | История просмотров |
| `/manage` | Управление каталогом: добавление, редактирование, удаление |
| `/about`, `/contacts` | Информационные страницы |
| `*` | Страница 404 |
